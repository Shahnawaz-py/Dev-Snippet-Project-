# DevPulse

DevPulse is a high-performance, minimalist code snippet manager and developer notes vault built with Next.js App Router and Tailwind CSS.

## Features

- **Snippet Vault**: Save, organize, edit, and categorize code snippets across frameworks and languages.
- **Instant Search & Tag Filtering**: Real-time multi-field search across titles, codes, descriptions, and custom tags.
- **One-Click Code Copy**: Copy snippets directly to clipboard with visual feedback.
- **Bookmarks & Favorites**: Star frequently used code snippets for fast access.
- **Local Persistence**: Automatically saves data locally in the browser.
- **Responsive Dark Theme**: Modern glassmorphism UI styled with Tailwind CSS.

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- Next.js (App Router)
- React & TypeScript
- Tailwind CSS
- Lucide React Icons

## Build for Production

```bash
npm run build
```
